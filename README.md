# YR Heaven Mobile Hub and Sublimation Printing

Full-stack business management and repair tracking web application for **YR Heaven Mobile Hub and Sublimation Printing** (Opposite Gramin Bank, Chhota Sheikpura, Narhat, Nawada, Bihar).

## Core Features
- **Public Website:** Service estimates, accessories catalogue, custom printing enquiry form, and no-login tokenized repair tracking.
- **Owner Dashboard:** Repair job lifecycle management, 1-click WhatsApp status updates, batch purchase history, stock movement auditing, and sales/payment tracking.

## Tech Stack
- **Backend:** Java 21, Spring Boot 3, Spring Security (JWT), Spring Data JPA, Flyway, MySQL 8
- **Frontend:** React, Vite, Tailwind CSS
